# Data

The CSV files in this folder are generated by `scripts/score_operating_data.py` with a fixed random seed. They are synthetic and are intended for portfolio demonstration only.

## Files

- `job_orders.csv`: open role metadata, priority, rate information, skill requirements, work structure, response rate, and recruiter owner.
- `weekly_funnel_metrics.csv`: weekly applicant, qualification, screen, submission, interview, offer, placement, dropoff, and recruiter-touch counts.
- `candidate_pipeline_events.csv`: synthetic candidate-stage events with source channel, stage, completeness, quality flags, and margin value.
- `data_quality_checks.csv`: preprocessing checks and issue counts by role.
- `market_skill_signals.csv`: skill-demand, supply, pay-rate, and market-pressure signals.
- `recommended_actions.csv`: generated owner-level actions for the highest-priority roles.

The data is modeled on common staffing delivery workflows: job orders move through sourcing, screening, submission, interview, offer, and placement; source data needs QA before reporting; and recruiters need short, action-oriented role recommendations.
